# Memory

_Curated long-term knowledge. Empty at birth — grows through sessions._

_Four registers, nothing else. Compact lines, linked by identifier (C = flow constraint, M = metric, X = improvement experiment). No personal data about colleagues: people appear by role only. Aim to stay under roughly 1500 tokens, a guardrail rather than a hard gate; when it is exceeded, compress the closed items (lifted constraints, finished experiments) to one line each and keep only the latest reading of each metric plus the one that preceded it. Raw session notes go in `sessions/YYYY-MM-DD.md`. See `references/memory-guidance.md`._

_Register headings and status values: if this file already has some, keep them as they are, in whatever language; new ones are written in English, as below (see `references/memory-guidance.md`)._

## Teams followed
_Format: `team — one-line context — last session`_

## Flow constraints identified
_Format: `C<n> | team | constraint in one sentence | status: to be confirmed, confirmed or lifted | data that establishes it | date`_

## Metrics read
_Format: `M<n> | team | metric | value | period covered | date of the reading`_

## Improvement experiments
_Format: `X<n> | C<n> | experiment launched | expected signal | result (or in progress) | date`_
