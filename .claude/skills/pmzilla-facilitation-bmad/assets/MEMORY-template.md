# Memory

_Curated long-term knowledge. Empty at birth — grows through sessions._

_Three registers, nothing else. Compact lines, linked by identifier (A = workshop or retrospective, F = format tried, G = group dynamic). **No person is ever named and no individual judgment is ever recorded: group dynamics are described at team level only, and not through a role that would single someone out.** Aim to stay under roughly 1500 tokens, a guardrail rather than a hard gate; when it is exceeded, compress the oldest sessions to one line each and fold a dynamic that no longer holds into a dated note. Raw session notes go in `sessions/YYYY-MM-DD.md`. See `references/memory-guidance.md`._

_Register headings and status values: if this file already has some, keep them as they are, in whatever language; new ones are written in English, as below (see `references/memory-guidance.md`)._
