# Changelog

All notable changes to PMZilla Lab are listed here, newest first. This file starts at the first public edition. Later versions are described in the releases of the public repository, one per milestone.

## First public edition

- First public edition of PMZilla Lab: the four product postures (Discovery, Delivery, Scaling, Facilitation) and the Critic sub-agent, in English.
- Searchable library (MCP server `pmzilla-library`), watch and triage tools, flow and dependency reports, coaching journal and cases module.
- Neutral starting files: empty book catalogue, empty watch sources, default triage settings in English, empty work queue.
- Everything personal (library, watch, journal, flow data, local settings) stays on your machine and out of Git: see `docs/pmzilla/installation.md`.
