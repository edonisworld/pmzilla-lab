# Outillage de fin et de test protégé (change finish-train-foundations, design D16 ; classes : change finish-single-b3-b6, B4, design D9 et D10). Un motif par ligne ; « # » commence un commentaire.
# Un motif qui finit par « / » est un préfixe de chemin ; sinon, un joker de type Git (« * » traverse les dossiers). Lue par tools/finish_checks.py dans origin/main, main local ET dans le sommet : l'union s'applique.
# Chaque ligne de motif finit par une étiquette de classe dans son commentaire, `#[juge]` ou `#[sensible]`, suivie d'un texte libre. L'étiquette est après « # » : le lecteur d'avant les classes lit les mêmes motifs. Sans étiquette (ou avec deux classes selon la révision), un motif compte `juge`.
# `juge` : l'outillage de fin lui-même (ce dont un changement peut changer le verdict d'une fin ou d'une garde sur le contenu d'une autre branche, ou le code qui tourne pendant une fin ou un commit). Une branche qui en touche un se termine par une fin unitaire (par un train d'une seule branche après B6).
# `sensible` : masquage, Jira, base et vues, qualité des histoires, données synthétiques, bibliothèque, veille et les outils que la fermeture y atteint : aucun verdict de fin ne les lit, leur risque est la confidentialité ou les données réelles. Une branche qui ne touche que des fichiers `sensible` peut entrer dans un train quand une revue Opus est enregistrée pour son sommet.

La fermeture de la liste est couverte par TestArbreReel (juge ou sensible) ; aucune règle de fermeture propre aux juges (R-20261030-34).
